# Word Detective: AI System Specification & Architecture

## 📋 Overview
This document outlines the conceptual design, probabilistic logic, and prompt framework developed during the Stanford *Probability for AI* (PAI) application process.

## 🎯 Core Mechanics & Bot Interaction
The project was designed interactively through guided AI alignment to solve linguistic puzzles using conditional probability:

1. **Problem Statement:** How to systematically narrow down unknown word states given character frequency priors.
2. **Probabilistic Approach:** 
   - Evaluating character likelihood based on context.
   - Eliminating low-probability branches using heuristic rules.
3. **Bot Co-creation:** Structured the functional requirements, edge-case handlings, and decision tree logic in collaboration with the Stanford PAI assessment environment.
